Project Name: FitLog 

FitLog is a companion designed to help you train with intent and log every set. Browse a curated library of lifts, lock them into daily plan, and track metrics in real-time as week's work adds up.

-----------------------------------------------------------------------------------------

Technology Used:
--> Next.js (App Router): Framework for building the UI and handling routing.   
--> TypeScript: Ensures type safety and robust code architecture.
--> Tailwind CSS & DaisyUI: For rapid styling, dark-mode theming, and responsive design. --> React Context API: For lightweight, global state management across components.React --> Toastify: For immediate user selection and notifications.

-----------------------------------------------------------------------------------------

Key Features:
--> Comprehensive Workout Library: Browse twelve exercises covering every major muscle group with detailed visual cards and quick stats.

--> Detailed Exercise Specs: View step-by-step instructions, equipment needs, difficulty, and targeted muscle groups for every lift.

--> Dynamic 'Today's Plan' Builder: Add exercises to your daily routine, track them, and mark them as "Done" as you progress through your workout.

-->Live Metrics Dashboard: Automatically calculates and updates your total planned exercises, minutes, and calories burned in real-time.

--> Save & Sort Functionality: Bookmark workouts for later and effortlessly sort your plans by duration, calories, or rating.
